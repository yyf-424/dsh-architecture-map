# n5 — Sidebar panel

- **Anchor:** `client.js#createGraphTab`
- **Group:** `g-client`
- **Kind:** module

Reads `.archmap/graph.json` through the workspaceFiles Remote for the active session, polls every 2s, renders header/toolbar/legend/detail and delegates drawing to n6. The detail card starts/opens `arch_discuss` children.

The tab is opened on demand: after n1's `/arch` command returns success, the client `command/executed` listener calls `ctx.sidebarRight.openTab('archmap.graph')`. Nothing auto-opens the panel on load (the earlier auto-open loop was removed).
