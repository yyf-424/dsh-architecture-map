# n5 — Sidebar panel

- **Anchor:** `client.js#createGraphTab`
- **Group:** `g-client`
- **Kind:** module

Reads `.archmap/index.json` through the workspaceFiles Remote and builds one source per registered project:
- local → `.archmap/graph.json`;
- remote → `.archmap/projects/<id>/graph.json`.

The header offers a source picker (persisted per workspace in localStorage) and a source status line (host/root/vcs/consent). Polling follows the selected source every 2s; positions are stored per workspace + source. A missing index falls back to the local project silently, while a corrupt index shows an error and still falls back. A missing graph is the normal empty state (remote projects get their own empty copy and creation hint); only corrupt/permission/IO errors show the error box. The detail card starts/opens `arch_discuss` children.

The tab is opened on demand: after n1's `/arch` command returns success, the client `command/executed` listener calls `ctx.sidebarRight.openTab('archmap.graph')`. Nothing auto-opens the panel on load (the earlier auto-open loop was removed).
