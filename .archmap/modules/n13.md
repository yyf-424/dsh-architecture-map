# n13 — Consent gate

## Responsibility

Keep remote file content out of the model context until the user explicitly
allows it. The gate owns session grants, the durable workspace grant in
`.archmap/index.json`, revocation and child inheritance. It returns a decision;
it never returns file content.

## Files

- `src/host/remote/consent.js` — `createConsentGate({ getUserQuestions, now })`.

## Decisions

- `isAllowed(ws, context)` → `{allowed, scope:'session'|'workspace'|null}`.
- `ensure(ws, context, {signal})` → `{allowed, scope}` or
  `{allowed:false, reason:'no-answerer'|'no-agent'|'ask-failed'|'rejected'}`.
- `allowSession(ws, context)` / `inherit(ws, child, parent)`.
- `grantWorkspace(ws)` — used by `/arch remote grant`; writes the durable
  record through `writeIndex` without asking a question.
- `revoke(ws, {sessionId?})` — one session, or all sessions plus the workspace
  record.
- `autoMaintenanceAllowed(ws)` — true only for a durable workspace grant.

## Invariants

- The approval question contains the host and root, never file content.
- Missing `userQuestions` fails closed; reject/skip leaves no grant.
- Workspace consent preserves other projects in the index.
- Auto maintenance is forbidden on a session-only grant.
