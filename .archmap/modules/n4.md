# n4 — Exporter

- **Anchor:** `src/host/export.js#createExporter`
- **Group:** `g-host`
- **Kind:** module

Produces deterministic Mermaid, standalone SVG and Markdown digest files under the project's `stateDir/export/`. Exports never modify the graph or manifest.

The exporter receives the resolved workspace descriptor and writes beside the project state, so a remote project exports into `.archmap/projects/<id>/export/` without touching the remote.
