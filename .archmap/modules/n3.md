# n3 — Memory store

- **Anchor:** `src/host/memory.js#createMemoryStore`
- **Group:** `g-host`
- **Kind:** module

Builds the file manifest, classifies code vs cosmetic changes via the normalized signature stored in the manifest, reports affected nodes, marks stale status and refreshes anchors. Also serves the `overview` / `modules` / `notes` dossier.

File access goes through the content source (n10): `scan()` supplies `{sha256, size, signature}` for every scanned text file, and `describe()` supplies the same fields for one commit candidate. The memory store no longer walks the filesystem itself.
