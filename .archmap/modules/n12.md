# n12 — Remote content source

## Responsibility

Implement the read-only content contract over the SSH transport: list remote
paths, batch-hash analyzed files, describe one commit candidate, serve bounded
reads, grep and compute a change fingerprint. File contents never land on the
local disk; only hashes and metadata cross the connection for sync.

## Files

- `src/host/remote/content.js` — `createRemoteContent({ client, root, vcs })`.

## Methods

| Method | Behavior |
|---|---|
| `listTree()` | git: `ls-files -z --cached --others --exclude-standard`; non-git: pruned `find`; ignored segments filtered |
| `hashMany(paths)` | batched `sha256sum` or `shasum -a 256`; missing/outside-root paths are skipped; 100 paths per command |
| `describe(rel)` | `missing / not-file / oversized / binary / text + size + sha256` without transferring content |
| `readText(rel,{maxBytes})` | `cat`, `null` for missing or oversized |
| `readRange(rel,{offset,length})` | `tail -c | head -c`, returns `{text,offset,bytes,eof}` |
| `grep(pattern,{include,path,context,maxResults})` | `rg` when present, else `grep -rInI`; exit 1 is an empty result |
| `stat(rel)` | `file / directory / null` |
| `fingerprint()` | git: HEAD + `status --porcelain -z`; non-git: path/size/mtime metadata digest |

## Invariants

- Only read-only remote programs are invoked: `git ls-files/status/rev-parse`,
  `find`, `cat`, `sha256sum/shasum`, `grep/rg`, `tail`, `head`, `wc`, `tr`,
  `printf`, `stat`, `readlink`.
- The configured root is canonicalized once. Every explicit read resolves the
  target with `readlink -f` and rejects it when it escapes the root; a symlink
  that stays inside the root remains readable, and one pointing outside is
  rejected.
- Non-git fingerprints read path/size/mtime only; content is hashed only for
  the files sync already tracks.
- Caps, timeouts, aborts and output limits are inherited from n11.
