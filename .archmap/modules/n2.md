# n2 — Graph store

- **Anchor:** `src/host/graph.js#createGraphStore`
- **Group:** `g-host`
- **Kind:** store

Owns `<stateDir>/graph.json`: schema validation, ordered ops, `baseRev` compare-and-swap, per-project lock, atomic temp-file rename and `graph.bak.json` backup. Reads are bounded text renderings.

The store receives a resolved workspace descriptor (n9) and asks the content source (n10) for anchor hashes, so the same code serves the local project and a future remote project. Local state stays at `.archmap/graph.json`; remote state lives at `.archmap/projects/<id>/graph.json`.
