Bundled skill and references: bootstrap, incremental sync/stale review, graph schema, discussion protocol and the remote-workspace workflow. The Host registers it as an embedded runtime skill.

## Remote rules

- `arch_remote_list` / `arch_remote_status` expose metadata without consent.
- `arch_remote_tree` / `arch_remote_read` / `arch_remote_grep` are the only way to inspect remote code; the first content access asks for consent.
- Never use local `read`/`grep`/`glob`/`bash` for a `remote:<id>` workspace.
- Graph and dossier writes stay in the local `.archmap/projects/<id>/`; never write remote files.
- `arch_sync` / `arch_manifest_commit` work on `remote:<id>`; sync hashes only manifest files. Use `/arch remote sync` / `/arch remote update` when the indexer reports pending changes.
