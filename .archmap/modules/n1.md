# n1 — Host entry

- **Anchor:** `src/host/plugin.js#apply`
- **Group:** `g-host`
- **Kind:** entry

Registers `arch_*` tools, the `/arch` command, the Mermaid static routes and the bundled skill. It composes the graph, memory and export services, passes the current workspace from the tool/session context, and optionally injects `ctx.userQuestions` into the remote consent gate.

A profile without `userQuestions` still loads; remote content then fails closed until a consent path exists.
