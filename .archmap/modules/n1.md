# n1 — Host entry

- **Anchor:** `src/host/plugin.js#apply`
- **Group:** `g-host`
- **Kind:** entry

Registers `arch_*` tools (including `arch_remote_*`), the `/arch` command, the Mermaid static routes and the bundled skill. It composes the graph, memory, export, consent, indexer and maintainer services; routes `/arch remote ...` to n17; and passes the current workspace from the tool/session context.

A profile without `userQuestions` still loads; remote content then fails closed until a consent path exists. The indexer timers are registered as an effect and disposed with the plugin.
